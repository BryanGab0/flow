# Flow

Jogo de parkour em primeira pessoa feito em Unity.

## Como jogar

Atravesse o percurso até a chegada. Se cair do cenário ou a vida chegar a zero, a fase reinicia.

| Tecla        | Ação                     |
| ------------ | ------------------------ |
| W A S D      | Andar                    |
| Shift        | Correr                   |
| Espaço       | Pular                    |
| Mouse        | Olhar                    |
| Esc / Clique | Soltar / prender o mouse |

## Como abrir

- Unity **6000.3.26f1** (URP)
- Unity Hub → **Add → Add project from disk** → pasta `flow`
- Abra a cena `Assets/_Project/Scenes/Main`
